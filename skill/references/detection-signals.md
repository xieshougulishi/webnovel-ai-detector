# 检测原理与信号清单

> 这份文档解释**为什么**某些文本特征能指示 AI 生成。
> 每个信号都标注了可靠度等级，等级定义见文末。

---

## 1. 底层机制：AI 文本到底留下了什么

主流 AI 文本检测（GPTZero、朱雀、Originality.ai 等）在原理上都围绕两个统计量：
**困惑度（perplexity）** 和 **突发性（burstiness）**。

- 语言模型生成时**每一步都在挑高概率词** → 逐词"意外度"偏低
- 更关键的是**意外度的方差很小** → 文本读起来"每条路都走得很稳"

人写作不是这样：一会儿用生僻词，一会儿用大白话，一会儿写病句，
一会儿甩一句八字短句。**方差大**。

本工具无法直接算困惑度（没有本地大模型），但困惑度的**统计后果**是可以间接观测的，
而且其中一部分比困惑度**更可解释**——这对作者申诉来说是决定性的优势。

| 底层机制 | 可观测后果 | 本工具怎么测 |
|---|---|---|
| 逐词挑高概率词 | 高频套话密度高、罕见词少 | 套话词表密度、字种丰富度 |
| 低困惑度方差 | 句长/段长方差小 | 句长变异系数、IQR、段长变异系数 |
| 概率平滑 | 回避极端选择（方言、脏话、错字） | 人味信号词表（反向计分） |
| 训练语的"文档腔" | 书面连接词密度高 | 连接词表密度 |
| RLHF 偏好完整闭合 | 段段收尾、句句升华 | 段末总结率、总结词密度 |
| 参考语料偏文艺 | 文艺腔套话超密 | 套话词表（**最强单条信号**） |
| 概率模型并联倾向 | 「不是A而是B」、排比 | 句式模板正则 |
| 无真实身体经验 | 情绪只写抽象词 + 通用身体反应 | 抽象情绪词表、身体反应词表、五感分布 |
| 无真实对话经验 | 对白太顺、太完整、标注单一 | 对白长度、标注多样性 |

**关键认识**：任何单条信号都不能定罪。人类也写"仿佛"，也用成语，也写排比。
定罪靠的是**多条痕迹同时密集出现** + **缺少反向的人味证据**。

## 2. 信号分级

### A 级（强证据，可靠度高）

实测中区分度最好，且机制清晰。

| 信号 | 为什么可靠 |
|---|---|
| **文艺腔套话密度** | 实测中区分度最大：真人网文常在 0–1.2/千字，AI 常达 5–22/千字。差一个数量级。机制清楚：模型训练语料里"文学性"文本以抒情散文、书评影评为重，为了显得有文笔会主动往这里靠。 |
| **总结/升华词密度** | 同样数量级差异（真人在 1.5 以下，AI 常 5–15）。对应 RLHF 的"完整闭合"偏好。 |
| **句式模板复用** | 「不是A而是B」「像……一样」这类结构在真人文本里是零散的，在 AI 文本里会**在同一段里反复用同一种**。这是模型句式贫乏的直接证据，不是统计推断。 |
| **生成器残留** | 「作为一个AI」「以下是我为你写的」这类直接痕迹。命中即强证据，虽然罕见。 |

### B 级（中等证据，需要与其他信号并发）

| 信号 | 说明与误差 |
|---|---|
| **句长变异系数偏低** | 机制清晰（低困惑度方差），但**真人写短样本时也可能偏低**。本工具只对 ≥30 句的样本评分。属启发式。 |
| **标点分布集中** | 人类标点习惯高度个人化（有人爱破折号，有人爱省略号）。AI 收敛。但**短样本上不稳定**，只在 ≥1200 字且 ≥4 类标点时评分。 |
| **抽象情绪词密度** | 命名情绪 vs 表现情绪。真人在激烈场景里也会密集用抽象词，所以基线给得较宽（6/千字）。 |
| **书面连接词密度** | 说明文腔。但**翻译腔作者与文学向作者天然偏高**，所以权重低。 |
| **对白标注单一** | 需要足够对白样本（≥8 次标注）才评分。 |
| **五感偏视觉** | 机制清楚（训练语料里嗅/味/触描写本就稀疏），但**短样本极不稳定**，只在 ≥2000 字评分。 |

### C 级（弱证据，单独命中不构成嫌疑）

| 信号 | 为什么弱 |
|---|---|
| **段长变异系数** | 题材影响大：对话密集的章节天然多短段。 |
| **单行短段占比** | 纯排版问题，后期可调，且不同作者习惯差异巨大。 |
| **每段句数变异系数** | 与上同。 |
| **对白占比过低** | 确有以叙述为主的题材（无限流、悬疑铺垫）。 |
| **长句占比** | 只作参考，不评分。 |

### D 级（反向信号：人味证据，用于对冲）

这些**降低** AI 嫌疑，且是申诉时最有用的材料。

| 信号 | 为什么难伪装 |
|---|---|
| **半角标点混入中文** | 中文输入法产生不了半角标点。只能来自人工敲击、跨来源复制拼接。AI 输出几乎 100% 规范全角。**这是最干净的人味信号。** |
| **脏话/粗话** | RLHF 后模型被强烈抑制输出脏话。整章一次都没有反而值得注意。 |
| **口语/俚语/方言** | 模型默认走书面语。方言用法更是训练数据里的长尾。 |
| **语气助词** | 分布极度个人化（吧/呢/啊/嘛/嘞），且模型使用显著偏少。 |
| **「的/地」混用等写作噪声** | 真人写作有噪声：状语「地」写成「的」、重复字、半全角混排。**"太干净"本身就是可疑信号。** 但不能反推"有噪声就一定是人"——噪声可以被刻意添加。 |
| **排版不规整** | 段落长度忽长忽短、对白与叙述交替无常。 |

## 3. 已知失效场景（必须如实告知用户）

| 场景 | 本工具的表现 | 原因 |
|---|---|---|
| **AI 文本经人工改写** | **低估** | 改写稀释了典型痕迹，但不会把它变成人写文本。改写程度越深，低估越严重。 |
| **高度程式化的题材**（系统流、签到流、战神文） | **可能高估** | 这类文本人写也会句式重复、段段收尾。已按题材放宽基线，但无法完全排除。 |
| **古风/文学向人写文本** | 可能高估 | 成语与书面连接词天然偏高。已按题材放宽。 |
| **翻译腔作者、非母语作者** | 可能高估 | 句式规律、连接词偏多。 |
| **AI 辅助润色**（人写大纲 + AI 扩写） | 中间档，难以定性 | 特征混合，本工具会给出较宽的区间——这是正确行为。 |
| **节选片段** | 判断力下降 | 切掉上下文后，节奏与结构类信号失真。报告会标注。 |
| **< 1000 字** | 不可靠 | 统计量不稳定。本工具强制放宽区间并标注低置信。 |
| **英文文本** | 不适用 | 词表与基线都是中文网文。 |

## 4. 与朱雀类工具的对比（用户常问）

| 维度 | 朱雀类黑箱 | 本工具 |
|---|---|---|
| 原理 | 困惑度 + 突发性（需服务端大模型） | 可本地观测的文体统计特征 + 规则证据 |
| 输出 | 单一百分比 | 风险区间 + 档位 + 逐条证据 |
| 定位能力 | 无 | 精确到字符区间，正文高亮 |
| 判据透明度 | 保密 | 公式、权重、词表全部印在报告里 |
| 反证 | 不给 | 专设「误判对冲」章节 |
| 申诉支持 | 无 | 生成可直接引用的申诉论据 |
| 误判处理 | 无处说理 | 给出"什么条件下结论会翻案" |
| 精度 | 未知（不公开评测） | 公开自测语料结果（见 `calibration.md`） |

**结论口径**：两者都只是概率估计。**本工具的优势不是更准，而是可复核、可申诉、可改进。**

## 5. 参考依据

本工具的信号设计参考了以下公开研究方向的结论（未逐篇引用，因为本工具是工程实现而非学术工作）：

- 基于**困惑度与突发性**的 AI 文本检测（GPTZero 等产品的公开方法论）
- **词汇多样性指标**（TTR、MTLD）在作者归属与生成文本识别中的应用
- **句长分布与节奏分析**在文体计量学（stylometry）中的传统用法
- **LLM 输出偏好的可测量性**：RLHF 后模型在情感表达、连接词选择、句式多样性上的系统性偏移
- 中文 AI 文本的**特征性套话词表**（工程经验积累，非单篇论文）

**诚实声明**：本工具的基线数值（如"真人套话密度 ≤1.2/千字"）来自小规模自建语料
（见 `calibration.md`）加工程经验，**不是大规模标注语料统计的结果**。
这也是为什么工具倾向于给出**区间**而不是定值——它承认自己的基线不够硬。
用户可以用自己的作品逐步替换基线，这是设计上留的口子。
