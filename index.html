网文 AI 痕迹检测

Agent Skill 检测中文网文的 AI 含量，并逐条列出判定原因——不是只丢给你一个分数。

  • AI 含量风险分 + 不确定区间，不假装精确
  • 命中哪几条特征、落在原文第几个字，可直接跳过去看
  • 实测值 vs 人类基线：为什么这条算异常，而不是凭感觉
  • 逐条改法：这个套话换成什么、哪句该删
  • 逻辑漏洞：自相矛盾 / 答非所问 / 语义跳跃
  • 申诉材料：被平台判为 AI 时可直接引用的论据

这是一个通用 Agent Skill：装进 Claude Code、DSH 或任何支持 Agent Skills 的客户端即可调用， 上述功能全在。本页是它的免安装网页版，跑同一套检测引擎，做量化分析这一部分。
